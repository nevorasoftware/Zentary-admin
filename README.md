# Zentary Admin Web (React + TypeScript + Vite + TailwindCSS)

Sitio web administrativo para la gestión del sistema residencial Zentary.

## 🚀 Características
- **Control de Accesos y Habilitación de Usuarios**: Activar, aprobar o deshabilitar el acceso de residentes a la aplicación móvil Zentary.
- **Envío de Anuncios**: Crear y difundir comunicados en tiempo real (Mantenimiento, Urgente, Eventos, General) directamente a los celulares de los residentes.
- **Control de Garita y Pases QR**: Monitorear visitas en curso, validar códigos QR y registrar vehículos de visitantes.
- **Recepción de Paquetes**: Registrar encomiendas recibidas en garita (DHL, FedEx, UPS, Cargo Express, Trans Express, Otro) con notificación automática al residente.
- **Gestión de PQRS y Soporte**: Responder a las solicitudes y chatear directamente con los residentes.
- **Mantenimiento y Pagos**: Emitir cobros masivos y monitorear el estado de cuotas (Pagado / Pendiente).
